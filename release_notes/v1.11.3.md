# finance_chart v1.11.3

## 财务三表 · 免 Key 可用

- **东财 F10 免 Key 第二源**：未配置同花顺 API Key 的用户也能查看财务三表（资产负债表 / 利润表 / 现金流量表）与核心财务指标，不再白屏。
- **修复 F10 文本响应未解码（P0）**：东财 `datacenter-web` 返回 `Content-Type: text/plain`，此前 Dio 未自动解码导致数据全空，已补 JSON 解码。
- **无 F10 覆盖的市场明确提示**：港股 / 美股 / ETF 等暂不支持财务三表的市场，直接提示「该市场暂不支持财务三表」，不再显示笼统的「暂无数据」。
- **修复 `toThsCode` 代码映射错误**：北交所 `920xxx` 此前被送往 `.SH`（应为 `.BJ`）、沪基金 `5xxxxx` 被送往 `.SZ`（应为 `.SH`），导致北交所财务数据静默空白；已修正。
- **端点级熔断优化**：标的级「无数据」不再计入端点熔断，避免看几个港美股就熔断东财数据源。

## 其他

- 个股详情页 AppBar 新增「详情」入口，打通 `StockDetailScreen`。
- 多数据源（情绪 / 个股信息 / 龙虎榜 / 宏观 / 资金流）接入东财镜像域，修正多个死域名引用。
- 新增 `firstSuccess` 端点级熔断 + 冷却复用工具，提升多源竞速稳定性。

## 下载说明

本版本提供 **4 个安装包**：

| 包名 | 适用设备 |
| --- | --- |
| `app-release.apk` | **通用版**，几乎所有设备均可安装（推荐大多数用户） |
| `app-arm64-v8a-release.apk` | 主流 64 位 ARM 设备（绝大多数现代手机） |
| `app-armeabi-v7a-release.apk` | 32 位 ARM 旧设备 |
| `app-x86_64-release.apk` | 模拟器 / x86 64 位设备 |

> 通用版体积最大但兼容性最好；分架构包更小、安装更快，按机型选择即可。两者均为正式签名，可直接覆盖安装 v1.11.2。
